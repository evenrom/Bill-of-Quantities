# Bill-of-Quantities

אפליקציה ייעודית להכנת כתבי כמויות. שלב נוכחי: אפיון מעודכן ובדיקת היתכנות לפורמט קבצים; המוצר טרם נבנה או נפרס.

## מסמכי הפרויקט

1. [PRD_BOQ.md](PRD_BOQ.md) — החלטות מוצר ודרישות, מהדורה 4 מ־26.10.2026.
2. [אפיון שש התבניות](docs/BOQ_TEMPLATE_SPEC.md) — התכולה המקצועית המלאה, ללא צורך בחזרה לארכיון.
3. [תכנון פורמט קובץ](docs/BOQ_FILE_FORMAT.md) — קובץ עבודה, קובץ תבנית, ייצוא וייבוא.
4. [תוצאות בדיקת תאימות](docs/BOQ_FORMAT_COMPATIBILITY_REPORT.md) — סבבי Excel ו־Google Sheets שבוצעו בפועל וגבולות הבדיקה.
5. [רפרנס העימוד](docs/references/BOQ_LAYOUT_REFERENCE.xlsx) — עיצוב בלבד; אין להעתיק תוכן או נתוני פרויקט ואין לשנות את הקובץ.

## החלטות מרכזיות

- אתר Vercel בכרום בשני מחשבי המשרד, ניתן להתקנה כ־Web App.
- שמירה ידנית/שמירה בשם לקובץ נבחר; אין מסד פרויקטים, אחסון פרויקטים בענן או רכיב שרת מקומי.
- קובץ העבודה שומר גם פרקים כבויים. ייצוא לקבלן כולל Excel ו־PDF של פרקים פעילים בלבד.
- חוסרים מוצגים לפני ייצוא עם אפשרות להמשיך במפורש. אין נעילת מחירים.
- קבצים חיצוניים נפתחים בייבוא מונחה למבנה המערכת.

בדיקת הנתונים המוקדמת עברה בשני המנועים; עימוד A4, הפורמט המלא ושמירה בכרום עדיין דורשים בדיקות במהלך המימוש. חומרי הניסוי בלבד נמצאים ב־`outputs/format-probe-20261026/`.
