# Bill-of-Quantities

אפליקציה ייעודית להכנת כתבי כמויות. שלב נוכחי: מימוש ראשון מקומי (27.10.2026), ללא פריסה. נבנה מסלול יצירה מתבנית מסעדה, עריכה, שמירה ופתיחה חוזרת של קובץ עבודה. עדיין לא מיועד להפקה לקבלן.

## הפעלה ופיתוח

נדרשים Node.js 22.12 ומעלה ו־Chrome. לאחר הורדת המאגר:

```powershell
npm ci
npm run dev -- --port 5174
```

פתחו `http://127.0.0.1:5174`. שרת Vite משמש לפיתוח בלבד; מוצר היעד הוא אתר סטטי ב־Vercel ללא שרת מקומי או אחסון פרויקטים בענן.

1. לחצו „פרויקט חדש”, מלאו פרטים כרצונכם ובחרו „יצירת פרויקט”.
2. ערכו תיאורים, יחידות, כמויות ומחירים. פרק כבוי ניתן לפתיחה לעריכת טיוטה.
3. לחצו „שמירה בשם” ובחרו קובץ `.xlsx` במחשב. „שמירה” מעדכנת אותו בכפוף להרשאה ובדיקת שינוי חיצוני.
4. לחצו „פתיחת Excel” ובחרו את קובץ העבודה להמשך עריכה. קבצים אחרים נעצרים עם הסבר עד להשלמת הייבוא המונחה.

אין שמירה אוטומטית. קובץ העבודה כולל גם פרקים כבויים ואינו קובץ להפצה לקבלן.

## בדיקות

```powershell
npm test
npm run build
npm run test:e2e
```

בדיקות הדפדפן דורשות Chrome מותקן, ומשתמשות בפורט 5174. הן מחליפות את חלונות הבחירה במתאם בדיקה ומבצעות קריאה וכתיבה דרך ממשקי קבצים אמיתיים של הדפדפן באחסון בדיקה זמני. האפליקציה עצמה אינה משתמשת באחסון זה. בדיקת חלונות Windows והרשאות בפועל עדיין נדרשת.

`npm run templates` מחלץ מחדש את תבנית המסעדה מהאפיון בלבד ובודק את מספרי הפרקים והשורות. אין קריאה מהארכיון או מקוד הניסוי.

מצב עדכני: [תיקונים בעקבות משוב](docs/FEEDBACK_FIXES_20261027.md) — הוספת סעיפים והערות, המרה וביטול, שער, מקרא, מסגרות, שמות לשוניות וריכוז עלויות. מיפוי התאים בפורמט הנוכחי: [סכמת v2](docs/WORKBOOK_SCHEMA_V2.md); קובצי [v1](docs/WORKBOOK_SCHEMA_V1.md) נשארים קריאים. [דוח השלב הראשון](docs/IMPLEMENTATION_STAGE_1.md) מתעד את הבסיס הקודם.

עדכון אחרון: [סכמת v3 והחלטות המשוב](docs/WORKBOOK_SCHEMA_V3.md) — מחיקת והקפאת שורות, ברירות מחדל לתאריך ומע״מ, פרטי משרד קבועים ושער מעודכן. v1 ו־v2 נשארים קריאים.

לוגו קבוע: `public/branding/office-logo.png` כבר נוסף ונבדק. הוא מוטמע בשמירה של מסמך שאין בו לוגו. כדי לעדכן קובץ עבודה קיים לעיצוב החדש, פתחו אותו במערכת ובחרו „שמירה בשם”.

## החלטות מרכזיות

- אתר Vercel בכרום בשני מחשבי המשרד, ניתן להתקנה כ־Web App.
- שמירה ידנית/שמירה בשם לקובץ נבחר; אין מסד פרויקטים, אחסון פרויקטים בענן או רכיב שרת מקומי.
- קובץ העבודה שומר גם פרקים כבויים. ייצוא לקבלן כולל Excel ו־PDF של פרקים פעילים בלבד.
- חוסרים מוצגים לפני ייצוא עם אפשרות להמשיך במפורש. אין נעילת מחירים.
- קבצים חיצוניים נפתחים בייבוא מונחה למבנה המערכת.

בדיקת הנתונים המוקדמת עברה בשני המנועים; היא אינה אישור לפורמט המוצר החדש. עימוד A4, הפורמט המלא, סבבי Excel/Sheets ובדיקת הרשאות כרום בשני המחשבים עדיין דורשים בדיקות במהלך המימוש. חומרי הניסוי בלבד נמצאים ב־`outputs/format-probe-20261026/`.
