# לוגו המשרד

שימו כאן את הקובץ הקבוע בשם `office-logo.png` (רצוי PNG שקוף, ברוחב 1200 פיקסלים ומעלה).

הכתובת באפליקציה היא `/branding/office-logo.png`. הלוגו נטען בעת יצירת פרויקט ובשמירה של פרויקט שעדיין אין בו לוגו, ומוטמע בקובץ העבודה כדי שיישאר עצמאי גם במחשב אחר. החלפת הקובץ אינה דורסת לוגו שכבר נשמר בפרויקט.

כל עוד הקובץ חסר, מוצג מציין מקום ברור. אין להשתמש בלוגו או בפרטי קשר שנלקחו מפרויקט ברפרנס.
