# סכמת v5 — הערות מתומחרות

25.11.2026. מחליפה את הגבלת ההערות בגרסאות הקודמות; יתר מבנה v4 נשמר.

- `note` אינה מקבלת מספר סעיף, אך יכולה להכיל יחידה, כמות ומחיר. המרה בין `item` ל־`note` משמרת את הנתונים.
- לכל שורת תוכן שאינה מוקפאת יש נוסחת סכום, גם אם היא הערה טכנית ריקה מכמות וממחיר. כך ניתן למלא הערה גם ב־Excel ללא שינוי מבנה הקובץ.
- סכום פרק כולל את כל שורות התוכן שאינן מוקפאות. הערה ללא כמות וללא מחיר אינה חוסר בתמחור; הערה שהוזנה בה כמות או מחיר נבדקת כשורת תמחור.
- העתקת הערה משמרת יחידה וכמות ומנקה מחיר, כמו העתקת סעיף.
- קבצי תבנית ממשיכים לשמור יחידות בלבד, ללא כמויות ומחירים, גם בהערות.
- קורא v5 תומך בקובצי פרויקט v1–v4 ובקובצי תבנית וקבלן v4. קבצים ישנים אינם משוכתבים בעת פתיחה; בשמירה הבאה נכתבת v5. יישום ישן עשוי לדרוש ייבוא מונחה לפתיחת v5.
- תאריך השער נשמר כמחרוזת `DD/MM/YYYY` בכיוון LTR ונקרא למודל כ־`YYYY-MM-DD`. גם תאריך ISO בקובץ ישן נתמך.
- תצוגות PDF ו־Excel מסתירות ערכים כספיים השווים בדיוק לאפס. Excel שומר ערכי אפס ונוסחאות ומשתמש במקטע אפס ריק בעיצוב המספר. כמות אפס אינה מוסתרת. ערך חיובי קטן אינו מסווג כאפס רק בגלל עיגול התצוגה.
- כותרת סיכום פרק היא `סיכום פרק N להעברה`. חיווי חוסר בתמחור נשמר בבדיקות ובסיכום הכללי.

כותרות הפרקים שמורות בתאי הכותרת וממשיכות להתעדכן בתוכן העניינים ובריכוז העלויות בכל הפקה. שינוי שם בפרויקט אינו משנה את התבנית המובנית.
