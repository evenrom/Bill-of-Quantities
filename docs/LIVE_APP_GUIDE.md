# התקנה ושימוש במערכת

כתובת קבועה: **https://bill-of-quantities-beta.vercel.app**

## התקנה בכל אחד משני מחשבי המשרד

1. לפתוח את הכתובת ב־Google Chrome בפרופיל הרגיל, ולא בגלישה בסתר.
2. אם מופיעה כניסה ל־Vercel, להזדהות בחשבון המורשה של המשרד. אין חשבון נפרד בתוך מערכת כתבי הכמויות. אפשר להשתמש בחשבון הקיים בשני המחשבים; חשבון נוסף דורש אישור גישה נפרד.
3. בעמוד הראשי ללחוץ **התקנה כאפליקציה**, ולאשר את ההתקנה בחלון Chrome. לחלופין להשתמש בסמל ההתקנה בשורת הכתובת. האפליקציה נפתחת בחלון ייעודי עם הסמל הכחול.
4. לסגור את החלון ולפתוח מחדש מקיצור הדרך. אם נדרש, להצמיד את האפליקציה לשורת המשימות או לתפריט ההתחלה דרך Windows.

יש להתקין מהכתובת הקבועה שלעיל, ולא מכתובת של פריסה בודדת. אין צורך ב־Node.js, בשרת מקומי או בקוד המקור על מחשבי המשתמשים. ההתקנה דורשת Chrome ואינטרנט; לא מומשה עבודה ללא חיבור.

## בדיקת קבלה קצרה בכל מחשב

1. ליצור פרויקט בדיקה, לשנות תיאור וכמות וללחוץ על אייקון השמירה. לבחור מיקום ושם קובץ בחלון Save As.
2. לחזור לתפריט הראשי, לבחור **המשך פרויקט קיים** ולפתוח את הקובץ. לוודא שהתוכן, הלוגו, הפרקים הכבויים והשורות המוקפאות נשמרו.
3. לשנות תיאור, לבחור שמירה ולבטל את חלון הבחירה. לוודא שהשינויים עדיין בעורך ושהחיווי מציין שלא נשמרו.
4. לבדוק תצוגת A4 ולבחור **ייצוא**. לאחר בדיקת החוסרים יורד Excel ונפתח חלון הדפסה; לבחור **שמירה כ־PDF**. אם Chrome חוסם את חלון ה־PDF, לאפשר חלונות קופצים לכתובת המערכת ולנסות שוב.
5. להעביר קובץ בדיקה למחשב השני, לפתוח אותו ולוודא שהתוכן תואם. יש לתאם מי עורך את הקובץ; אין עריכה מקבילה או נעילה מרכזית.

## שמירה ועדכונים

אין שמירה אוטומטית ואין שמירת פרויקטים ב־Vercel. קובץ העבודה נשמר במיקום שבוחרים, כולל פרקים כבויים. ייצוא לקבלן הוא פעולה נפרדת ומשמיט תוכן כבוי ומוקפא.

יש לבחור במשרד תיקייה מוסכמת ולגבות את קובצי העבודה. אין להעביר קובץ עבודה לקבלן במקום הייצוא המיועד לו.

לפני רענון או טעינת גרסת אתר חדשה, לשמור את העבודה. עדכוני האתר אינם משנים קובצי פרויקט קיימים ואינם דורשים התקנה מחדש של קיצור הדרך. אם תוקף ההזדהות פג, יש להיכנס שוב ל־Vercel.
