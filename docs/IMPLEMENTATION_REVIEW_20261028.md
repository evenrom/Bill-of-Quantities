2. בחרו שורות בתיבות הסימון, פתחו „פעולות בשורות” או לחצו לחיצה ימנית. העתיקו והדביקו בפרק אחר; ודאו שהמחיר ריק.
3. חפשו טקסט ולחצו על תוצאה. הפעילו „בדיקת חוסרים” ועברו לתיקון.
4. פתחו „תצוגת A4”. לחצו על תיאור לחזרה לעורך. בחרו „ייצוא לקבלן”, עברו על החוסרים ואשרו.
